# Angadveer_RTOS_Development

Welcome to the **Angadveer_RTOS_Development** repository.

This repository contains my work, experiments, notes, and implementations related to **Real-Time Operating Systems (RTOS)**. The purpose of this repository is to document my learning journey, practical experiments, and development activities carried out as part of RTOS laboratory coursework and self-study.

The repository is designed to maintain a clean and professional structure for organizing RTOS concepts, source code, experiment documentation, outputs, and learning resources.

---

## Objectives

* Understand the fundamentals of Real-Time Operating Systems
* Learn task management and scheduling techniques
* Explore synchronization mechanisms such as semaphores and mutexes
* Study inter-task communication methods
* Gain hands-on experience with embedded systems programming
* Practice version control and project documentation using Git and GitHub

---

## Technologies and Tools

* C Programming Language
* FreeRTOS
* Embedded Systems Concepts
* Git & GitHub
* STM32 / Arduino / ESP32 (as applicable)
